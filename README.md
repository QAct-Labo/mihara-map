# 道の気配MAP｜三原市版 Viewer v0.6.27

東広島市版 Viewer v0.6.27 の公開ベースラインを、三原市の交通事故データへ移植した版です。

## 収録範囲

- 対象：広島県三原市
- 警察庁オープンデータ上の都道府県コード：73（広島）
- 市区町村コード：204（三原市）
- 実発生年：2019〜2024年
- 収録事故：**668件**

年別件数：
- 2019年：146件
- 2020年：116件
- 2021年：107件
- 2022年：100件
- 2023年：108件
- 2024年：91件

## Viewer機能

公開版の基準は東広島市版 v0.6.27 と同じです。

- 個別事故点
- 集計表示
- 人対車両／自転車関与／車両相互／車両単独の絞り込み
- 年フィルタ
- 事故ID検索
- 多角形による「範囲を囲んで集計」
- 範囲集計ポップアップの保持
- Googleマップ／ストリートビュー連携
- AI読み用入力文のコピー
- CSV保存

## 三原市版で未収録のもの

行政・施策・施設などの参照レイヤーは、三原市について出典・位置精度を確認していないため初期版には搭載していません。

また、内部PoCとして作成した太陽関連レイヤーは搭載していません。

## データ変換・検証

東広島市版で検証済みの変換仕様を、そのまま三原市コード204へ適用しました。

- 事故記録：668/668件
- コード表変換：16,032/16,032項目値
- 緯度経度変換：668/668件
- 20m連結成分クラスター：83クラスター
- 埋込DATA SHA-256：`fc7a6b72da31d2abe41bb9615db87f03b2e699d10c4a620696f6a9c571038780`

2019〜2024年の各年度コード表を使用し、年度ごとのコード→区分名変換を行っています。
緯度経度は警察庁の度分秒表記を十進法へ数値変換しています。

## 注意

地図上の件数・構成比・近接関係は、事故原因、将来の危険率、対策効果を直接示すものではありません。
現地確認の問いを見つける入口として使用するViewerです。
